# Согласованный визуальный концепт

`approved-thermal.png` — сгенерированный Imagegen концепт, который пользователь утвердил 14.10.2026 как направление замены тепловой карты. Исходный файл: `exec-2f18465d-8fa2-45cb-87bc-e13ff662db2c.png`.

В основе — предоставленный снимок интерфейса с парковкой CNRPark-EXT, камера 8. Источник исходных наблюдений, авторы и условия ODbL указаны в [examples/README.md](../../examples/README.md). Изображение концепта изменено генератором: цвета, подписи, проценты и расположение элементов служат иллюстрацией и не являются результатом анализа.

Программа не использует концепт как данные или готовый тепловой слой. Она рассчитывает поле по реальным результатам модели. Реализация сохраняет полный исходный кадр 4:3; карта конкретной парковки окрашивается по фактической занятости и постоянной шкале 0–100%. Устройство описано в [HEATMAP.md](../HEATMAP.md).
