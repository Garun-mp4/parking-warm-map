# Новое видео: Moonbeam Parking Lot

Источник — публичная камера [Moonbeam Parking Lot на YouTube](https://www.youtube.com/watch?v=ta-4QZbfMXc), Solitude Mountain Resort, штат Юта. [Официальная страница курорта](https://www.solitudemountain.com/discover-solitude/getting-here-parking) описывает парковку и её камеру. Это другой ракурс и другой источник по сравнению с CNRPark-EXT.

Подготовлен интервал потока за 13 октября 2026 года, приблизительно **13:00–01:00 UTC следующего дня**: **12 часов**. Камера направлена на парковку с высоты, весь исходный кадр сохраняется. В выбранный день есть приезды и отъезды автомобилей, дождь, снег, туман и смена освещения; парковка заполнена умеренно. Время основано на метаданных потока YouTube и может отличаться от момента съёмки на задержку передачи.

Результат — **9 минут 36 секунд**, **75×**, **1280×720**, H.264, **15 кадров/с**, без аудио. Для ускоренного ролика берётся один исходный ключевой кадр из каждого пятисекундного фрагмента. Получается **8 640 исходных моментов**, вместо 21 снимка в старом примере. События специально не отбираются: пустые интервалы и изменения погоды тоже остаются. Синтетическая интерполяция кадров не используется.

## Локальные файлы

- `data/new-video/moonbeam-2026-10-13-12h-75x-compact.mp4` — готовое видео для сайта, около 109 МБ.
- `data/new-video/moonbeam-2026-10-13-12h-75x.mp4` — версия с более высоким качеством, около 370 МБ.
- Одноимённый `.json` — источник, длительности, ускорение, разрешение, число кадров, SHA-256 и результат проверки.
- Одноимённый `.jpg` — дневной кадр для предварительного просмотра.
- `data/source-cache/ta-4QZbfMXc-20261013T130000/` — исходные видеофрагменты, их времена и список для FFmpeg. Скачивание возобновляется без повторной загрузки уже полученных фрагментов.

Видео и кэш хранятся локально в исключённом из Git каталоге `data/`. У публичного эфира не указана открытая лицензия на дальнейшее распространение; его доступность для просмотра не выдаётся за такую лицензию. В репозиторий входят скрипты и описание происхождения.

## Использование в программе

После регистрации на сайте появится отдельное исследование **«Moonbeam · 12 часов · ускорение 75×»**. Исходный пример из Пизы сохраняется. Известный коэффициент ускорения восстанавливается из длительностей подготовленного файла и исходного потока; повторный анализ использует настройки последнего запуска.

У этой камеры собственный ракурс, поэтому исходная разметка Пизы к ней не применяется. Новое исследование создаётся с пустой разметкой: откройте «Разметка», выделите интересующие места и запустите анализ. Качество распознавания для новой камеры ещё не измерено. Низкая освещённость, снег и туман особенно требуют проверки результатов; утверждать прежнюю точность CNRPark для этого видео нельзя.

Если загружать только MP4 через обычное окно «Новое видео», задайте **«Ускорение исходника: 75»** перед анализом. Сам MP4 не сообщает приложению достоверную исходную длительность. Автоматически восстановить неизвестное ускорение чужого ролика невозможно.

## Повторная подготовка

В установленном проекте, из корня:

```powershell
.\.venv\Scripts\python -m pip install -r requirements-sources.txt
.\.venv\Scripts\python -m scripts.prepare_parking_video --start 2026-10-13T13:00:00+00:00 --hours 12 --workers 12 --output data/new-video/moonbeam-2026-10-13-12h-75x.mp4
.\.venv\Scripts\python -m scripts.compact_prepared_video data/new-video/moonbeam-2026-10-13-12h-75x.mp4
.\.venv\Scripts\python -m scripts.register_prepared_video data/new-video/moonbeam-2026-10-13-12h-75x-compact.mp4 --title "Moonbeam · 12 часов · ускорение 75×"
```

Архив публичной прямой трансляции имеет ограниченную глубину. Указанный исторический интервал со временем станет недоступен на YouTube; сохранённые локальные фрагменты и готовый MP4 от этого не исчезают. Для новой даты нужно выбрать другой доступный интервал. Скрипт не записывает эфир в реальном времени и не восстанавливает недоступные часы.

При скачивании проверяются тип и времена исходных фрагментов, их последовательность и полнота HTTP-ответов. Готовый файл проверяется FFprobe по длительности и количеству кадров, затем полностью декодируется FFmpeg. Регистрация сверяет SHA-256 и соотношение исходной и ускоренной длительностей; существующее исследование с тем же файлом повторно не создаётся.

Для повторного кодирования полностью сохранённого кэша добавьте `--encode-cache` к команде подготовки; сетевые запросы тогда не нужны. Для соединения современных фрагментированных MP4 используется отдельный FFmpeg 7.1 из `imageio-ffmpeg`, установленного только для подготовки источников. Проверяется также соответствие пяти кадров готового видео их исходным кадрам. Системный FFmpeg не заменяется.

Компактная копия сохраняет все 8 640 кадров, разрешение и длительность, ограничивая битрейт 1,8 Мбит/с. Её размер — **108 777 763 байта** (около 109 МБ); версия с высоким качеством — 369 900 679 байт. SHA-256, источник, времена и измеренные ошибки сравнения кадров: [new-video-validation.json](new-video-validation.json). Между временами поступления соседних фрагментов встречаются задержки до 19 секунд; заявленный шаг 5 секунд относится к медиашкале исходного потока.

Проверки: **25 pytest**, **9 Vitest**, Ruff, ESLint, TypeScript/Vite build. `scripts/browser-new-video.js` выполнен на настоящем добавленном видео: длительность 576 с, 1280×720, отсутствие ошибок браузера, воспроизведение/пауза, перемотка до конца, правильное время UTC, восстановление 75× после обновления и мобильный экран. Исходное исследование Пизы и его результат сохранены. Автоматический анализ и оценка качества модели на Moonbeam не выполнялись.

Запись пересекает полночь: интерфейс отмечает следующий день как `(+1 д)`, сохраняя корректную шкалу исходных часов. Новый проект до анализа открывается в обычном цветном видео; режимы состояний и тепловой карты становятся доступны после расчёта.
