# Реальные данные примера

Источник: [CNRPark-EXT](http://cnrpark.it/), Amato, Carrara, Falchi, Gennaro, Vairo. Исходные изображения и метаданные опубликованы авторами в [архиве deep-parking](https://github.com/fabiocarrara/deep-parking/releases/tag/archive).

Данные распространяются по [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Этот производный набор сохраняет указание источника и условия ODbL. Лицензия данных не заменяется лицензией программы. При использовании и дальнейшем распространении данных сохраняйте это указание.

- `cnrpark-day/frames`: неизменённые полные кадры камеры 8 за 16.11.2015, исходный архив `CNR-EXT_FULL_IMAGE_1000x750.tar`.
- `cnrpark-day/parking-day.mp4`: производный таймлапс из 21 реального кадра, по 2 секунды на кадр, H.264; размер примерно 2,3 МБ.
- `cnrpark-day/poster.jpg`: один из тех же исходных кадров, без искусственной генерации.
- `cnrpark-day/manifest.json`: точные времена кадров, геометрия областей мест из camera8.csv, уменьшенная из 2592×1944 в нормализованные координаты.
- `validation`: исходные кадры камеры 8 за 12.02.2016 для отдельной проверки.
- `reference-labels.json` и `cnrpark-day/truth.json`: выбранные эталонные состояния из авторского CNRPark+EXT.csv. **Worker их не читает**; они нужны только для оценки качества.

Период демонстрации: **07:22–17:34, 10 часов 12 минут**. Исходные наблюдения разделены интервалами около 30 минут; это не непрерывное видео. Между кадрами нельзя определить точный момент приезда, отъезда или короткий визит. Проценты и длительности — оценка по последнему наблюдённому состоянию. Последнему кадру не добавляется выдуманный дополнительный получасовой интервал.

Модель mAlexNet скачивается отдельно из [публичного архива авторов](https://github.com/fabiocarrara/deep-parking/releases/download/archive/CNRPark+EXT_Trained_Models_mAlexNet.zip). Используется `mAlexNet-on-CNRParkAB_all-val-CNRPark-EXT_val/snapshot_iter_870.caffemodel`: обучение на CNRPark A/B, выбор checkpoint по авторской CNR-EXT validation. Локального обучения на эталонах демонстрации нет. YOLO11-веса доступны у Ultralytics и используются с соблюдением их условий AGPL-3.0.
