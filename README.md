# Парковка — карта занятости

Локальный сайт на React: разметка парковочных мест, распознавание занятости по видео, тепловая карта, временная матрица, график и экспорт PNG/CSV/MP4. Python/FastAPI обрабатывает видео отдельным процессом; проекты и результаты сохраняются в SQLite.

## Запуск

На этом компьютере откройте **`Запустить.cmd`**. Адрес сайта: **http://127.0.0.1:8765**. Повторный запуск открывает уже работающий сайт. Для остановки сервера откройте `Остановить.cmd`; активный анализ перед этим отмените на сайте.

Для первой установки после клонирования: **`Установить.cmd`**, затем `Запустить.cmd`. Нужны Python 3.12+, Node.js 22.12+, FFmpeg и FFprobe в PATH; на компьютере разработки они установлены. Скрипт создаёт `.venv`, устанавливает зависимости, выполняет `npm ci`, собирает React и подготавливает пример. Активация окружения не нужна.

Установка требует интернет для зависимостей и небольшого архива весов mAlexNet (1,7 МБ). После этого пример работает локально без сети, аккаунтов и API-ключей. YOLO11n/s скачиваются при первом выборе; после скачивания тоже работают локально. Сервер слушает только loopback.

## Реальный пример

В репозиторий включены данные [CNRPark-EXT](http://cnrpark.it/): высокая неподвижная камера, **16.11.2015, 07:22–17:34 — 10 часов 12 минут**, 54 области мест. MP4 занимает **около 2,3 МБ**, воспроизводится за 42 секунды. Большой исходный архив для обычного запуска не нужен.

**Это таймлапс из 21 реального снимка примерно каждые 30 минут, а не непрерывная запись.** Между снимками занятость оценивается по последнему наблюдению. Короткие визиты и точные минуты приезда/отъезда определить нельзя. Ограничения показаны на сайте. Последнему кадру не добавляется выдуманный дополнительный интервал.

Источник, времена кадров, лицензия ODbL и авторы: [examples/README.md](examples/README.md). Дополнительно включён другой день для оценки качества. Полный компактный набор примера и проверки — около 14 МБ.

## Сценарий защиты

1. Выберите «Рабочий день в Пизе». В «Разметке» покажите области наблюдения.
2. В «Обзоре» выберите mAlexNet, порог 70%, нажмите «Рассчитать карту». Выполняется настоящий анализ; эталонные ответы модели не передаются.
3. Воспроизведите запись. Время рядом с ползунком относится к исходной съёмке. Счётчики «На кадре» относятся к этому моменту; тепловой слой показывает занятость за выбранный период.
4. Переключите тепловую карту, выберите место и временной диапазон. Покажите график, матрицу и таблицу.
5. Нажмите ячейку матрицы для перехода к кадру. Стрелки клавиатуры перемещаются между ячейками.
6. Скачайте PNG, CSV и MP4. PNG сохраняет текущий кадр с картой выбранного периода и настройками слоя, CSV — числа периода. MP4 содержит всю запись с картой выбранного периода; в режиме «Занятость» экспортируются состояния кадров.
7. В «Методике» объясните источник, неопределённые состояния, оценку между снимками и проверку модели.

## Плавная тепловая карта

По умолчанию открывается сине-красный тепловой слой: синий означает редкую занятость, красный — высокую. Старые фиолетовые заливки и постоянные рамки мест заменены мягкими пятнами. Доступны жёлто-красная палитра и непрозрачность 0–100%. Числа модели при переключении этих настроек не меняются.

У пятен широкая насыщенная середина и мягкая граница. Прозрачность не зависит от количества соседних мест; переходы оттенков сохраняют насыщенность. Фон видео приглушён, начальная непрозрачность карты — 85%. Эти параметры общие для сайта и PNG/MP4, подробнее — [HEATMAP.md](docs/HEATMAP.md).

Наведите курсор или нажмите на место: карточка показывает точный процент среди известных интервалов и покрытие. Стрелки переключают места; Enter/Space закрепляют карточку, Escape закрывает. Места без определённых данных — серая штриховка; за пределами размеченных областей слой прозрачен. Шкала всегда 0–100%, поэтому действительно загруженная парковка преимущественно тёплая.

Слой и легенда на сайте, в PNG и MP4 используют один генератор и общую палитру. Мягкость — визуальное обобщение соседних мест, а не дополнительные наблюдения между снимками. Подробности: [docs/HEATMAP.md](docs/HEATMAP.md).

## Собственное видео

«Новое видео» принимает MP4/MOV/AVI/MKV до 500 МБ. Камера должна быть неподвижной. Приложение проверяет декодирование и подготавливает H.264-копию, сохраняя оригинал. Ограничение длительности — 8 часов; подготовка длинной записи может занять много времени. Для защиты удобен компактный таймлапс.

В редакторе нажмите «Добавить», укажите 3–16 вершин выпуклого полигона и «Замкнуть место» либо Enter. Escape отменяет построение. Вершины выбранного места перетаскиваются; доступны удаление, отмена, название и сохранение. Постоянно закрытые места размечать не следует.

mAlexNet использует прямоугольный кроп вокруг полигона: он должен содержать автомобиль и минимум соседнего места. YOLO сопоставляет рамки с полигонами. На других ракурсах качество требуется проверять заново.

Для заранее ускоренного видео укажите известное «Ускорение исходника»: например, 120× означает две минуты исходной съёмки на секунду ролика. Неизвестный коэффициент не позволяет восстановить реальные длительности. В демонстрации используются точные времена снимков, а не предположительный коэффициент.

## Проверка моделей

Основная модель — публичная **mAlexNet**, обученная авторами на CNRPark A/B. Также реализованы **YOLO11n** и **YOLO11s**. Дообучение не выполнялось: на отдельной дате готовый классификатор получил F1 ≈ **0,959**, точность среди определённых состояний ≈ **98,86%**, покрытие ≈ **89,44%**. Неопределённые положительные примеры снижают recall/F1; отказы не скрываются.

Порог 0,70 выбирается на первом дне. Второй день не участвует в выборе порога скриптом. Это проверка другой даты той же камеры, не обещание переноса на любую парковку. Авторский checkpoint ранее выбирался на авторском validation CNR-EXT; оговорка есть в отчёте.

Точные параметры, метрики и SHA-256 весов: [docs/validation.json](docs/validation.json). YOLO11n на первом дне получил F1 ≈ 0,979, YOLO11s ≈ 0,887. Оценка касается состояний в моменты снимков, не точности длительностей между ними.

## Проверки и разработка

Из корня:

```powershell
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\ruff check backend scripts tests
.\.venv\Scripts\python -m scripts.validate_models
```

Из `frontend`:

```powershell
npm run lint
npm test
npm run build
npm audit
```

Браузерный сценарий требует установленного `playwright-cli` и запущенного сайта:

```powershell
ffmpeg -y -i data/demo/parking-day.mp4 -t 4 -c copy data/qa-upload.mp4
playwright-cli -s=parking open http://127.0.0.1:8765
playwright-cli -s=parking run-code --filename=scripts/browser-smoke.js
```

Сценарий создаёт проект `QA · проверка загрузки`, добавляет и отменяет полигон, проверяет отмену обработки, скачивает экспорты и снимает desktop/mobile. Это реальные действия в локальной базе: запускайте на тестовых данных. Отчёт о выполненных проверках — `docs/VALIDATION.md`.

Отдельный сценарий новой карты: `playwright-cli -s=parking run-code --filename=scripts/browser-heatmap.js`. Требует рассчитанного примера; проверяет реальный Canvas, точные карточки, палитры/непрозрачность, интервал, экспорты, восстановление после намеренно имитированного HTTP 500, fullscreen и mobile. Он не меняет разметку и не запускает модель повторно.

Разработка: `npm run dev` в `frontend` и `.\.venv\Scripts\python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765` в корне. Vite проксирует `/api`; готовую сборку обслуживает FastAPI.

## Данные и оформление

`data/` хранит базу, загрузки, результаты и журналы; `models/` — веса. Оба каталога исключены из Git. Результат связан со своей версией разметки. Закрытие вкладки не останавливает worker. Прерванный после аварии анализ можно запустить повторно.

Оформление оболочки следует предоставленному [DESIGN.md](DESIGN.md): белый canvas, чёрные тексты и кнопки, пастельные блоки, pill-кнопки, Inter/JetBrains Mono как разрешённые замены, видимый focus и reduced motion. Палитра данных изменена по выбранному пользователем тепловому концепту; её источник — shared/heatmap.json. Шрифты размещены локально с OFL-лицензиями.
